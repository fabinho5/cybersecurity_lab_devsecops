# LLM Experiment Configuration

Date: 2026-11-05
Model: GPT-6
Reasoning effort: High
Interface: ChatGPT (direct chat)

Experimental conditions:
- A: Source only
- B: Source + application context
- C: Source + application context + security requirements

Methodology:
- Same model and reasoning effort across all conditions.
- Three fresh, independent conversations.
- One review request per condition.
- No coding agents, browsing, tools, or repository access.
- No additional contextual information.
- Original prompts and responses preserved without modifications.
